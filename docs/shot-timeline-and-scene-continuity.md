# 镜内时间线与场景连续性方案

## 目标

一个外层分镜代表一个连续剧情事件，内部可以包含多个镜头段。每个镜头段先确定构图，再声明当前画面实际可见的人物，最后描述这些人物在该时间窗口内的动作、反应、视线和结束状态。

镜头段不是无条件复制整镜人物清单：特写可以只出现一个人，双人中景必须覆盖两个人，过肩镜头按实际可见的主体和肩部人物处理，画外说话者只进入声音槽位。

## 镜内时间线

`video_slots.shots_timeline` 的每一段包含：

- `timestamp`、`duration`：连续的整数秒窗口；
- `camera`：景别、运动和运动说明；
- `visible_characters`：本段实际入画的角色 ID；
- `action`、`result`：本段发生的事件及其结果；
- `character_trajectories`：只覆盖 `visible_characters`，每人填写动作、终态、表情、朝向、头部姿态、视线目标、注意对象、反应触发和口型；
- `audio_lip_sync`、`speech_action_alignment`：本段声音、对白和同步反应。

后端只校验本段 `visible_characters`，不为没有入画的人物补动作，也不静默删除 Agent 输出的人物。可见人物缺少轨迹时退回导演 Agent。

镜头段之间必须承接上一段的终态。对白跨切镜连续，不能重复起句；动作不能在切镜后重置。H3 收到的是一条连续视频的多段镜头规划，时间线是生成约束，不是后端自动剪辑点。

## H3 串行与场景连续性

当前 H3 执行器全局串行，按分镜顺序生成，不并行提交长视频任务。

导演 Agent 为每个分镜明确规划场景连续性：

- 同一场景且剧情连续：`continuity_mode=inherit_tail`，`first_frame_policy=inherit_tail`，等待前一镜完成后抽取其实际视频尾帧，作为当前镜首帧；
- 切换场景：不继承上一镜尾帧，使用新场景和角色参考，以 Ref2VA 重新起镜；
- 同一场景但剧情明确重新起镜：不继承尾帧，使用 Agent 指定的 Ref2VA 起始方案；
- 场景切换、时间跳跃或换装时禁止 `inherit_tail`。

执行器不得根据场景名称或素材缺失自行猜测、静默降级。前置分镜没有完成或真实尾帧抽取失败时，继承尾帧的分镜必须阻断并返回错误。

## 预期闭环

```text
导演 Agent 规划镜头段构图和可见人物
→ 本体门禁校验每段人物覆盖与终态承接
→ H3 按分镜顺序串行生成
→ 同场景连续镜继承真实上一镜尾帧
→ 切场景镜头使用 Ref2VA 重新起镜
```

这套规则解决“特写强行要求画外人物动作”和“双人画面只有一人有动作”两个相反问题，同时保持场景连续性和 H3 的串行显存策略。
